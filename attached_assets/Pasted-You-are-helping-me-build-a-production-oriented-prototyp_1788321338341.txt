CORE DESIGN PRINCIPLE

This is NOT a simple transaction matching system.

The system should determine whether a financial control invariant holds.

Each domain has a domain-specific invariant, but all domains produce a common residual representation.

The anomaly engine should analyze the DISTRIBUTION and evolution of residuals, rather than treating every transaction mismatch independently.

The AI agent should investigate detected control anomalies using tools and evidence.

LLMs must NOT be responsible for financial arithmetic.
All monetary calculations must use deterministic code with Decimal arithmetic.

The AI agent must NOT directly modify financial records.
It can investigate and recommend actions.
Actual resolution requires explicit controller approval.
