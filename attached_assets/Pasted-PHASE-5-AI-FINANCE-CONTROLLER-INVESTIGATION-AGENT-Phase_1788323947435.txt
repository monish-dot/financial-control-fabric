==================================================
1. CONTROLLER RESPONSIBILITY
==================================================

Create an AI Finance Controller that operates over the existing deterministic control infrastructure.

The controller workflow is:

PERCEIVE
→ HYPOTHESIZE
→ INVESTIGATE
→ CALCULATE
→ VERIFY
→ EXPLAIN
→ RECOMMEND
→ WAIT FOR APPROVAL
→ REVALIDATE

The controller receives:

- control result
- residual observations
- anomaly score
- distribution metrics
- reconciliation results

It then investigates why the control failed or why residual behavior changed.

==================================================
7. RETRIEVAL FAILURE VS REASONING FAILURE
==================================================

Explicitly separate:

RETRIEVAL FAILURE

from

REASONING FAILURE

For every investigation track:

retrieval_status
reasoning_status

Possible retrieval statuses:

SUCCESS
NO_EVIDENCE
INSUFFICIENT_EVIDENCE

Possible reasoning statuses:

CONSISTENT
INCONCLUSIVE
CONTRADICTED

This is important.

If the system cannot find the relevant transaction, it should not pretend the transaction does not exist.

If evidence exists but hypotheses cannot explain the control failure, report reasoning uncertainty.

==================================================
8. INVESTIGATION STRATEGY
==================================================

Given a failed control, generate a small deterministic set of candidate hypotheses.

Examples:

NODAL_ESCROW:

- missing bank credit
- missing payout
- duplicate payout
- late refund
- incorrect adjustment
- bank posting delay
- ingestion gap

MERCHANT_PAYOUT:

- missing payout
- incorrect fee
- incorrect tax
- refund mismatch
- duplicate payout
- adjustment mismatch

SETTLEMENT:

- partial settlement
- delayed settlement
- duplicate settlement
- missing partner confirmation
- bank posting difference
- fee/adjustment difference

REVENUE_RECOGNITION:

- recognition timing difference
- missing recognition entry
- duplicate recognition
- contract schedule mismatch

CROSS_ENTITY:

- missing intercompany side
- timing mismatch
- amount mismatch
- FX/configuration issue
- duplicate journal

Do not automatically label any issue as fraud.
